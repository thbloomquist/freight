Getting Started

Overview
The Document API is a REST service which returns documents for an associated PRO number.


For more information on all our API services, visit the Shipping API Integrations Page at ODFL.com.




Testing
We offer a QA environment for onboarding and testing purposes. To get started, visit the Shipping API
Integrations Page and click “Email an Expert” for help.

Best Practice
Bearer Token
       •   Caching the Bearer Token to be used multiple times
       •   Expires after one hour
       •   The expiration date and time is returned in response as Epoch time
Sending Request
       •   The only documentType that may change is “Invoice”
       •   Outside of documentType “Invoice”, once a document is obtained, there’s no need to
           continue sending request for that documentType

Number of Requests
Each pro number should be limited to a maximum of 12 requests per hour. Any calls exceeding this
limit may be throttled at ODFL's discretion.
